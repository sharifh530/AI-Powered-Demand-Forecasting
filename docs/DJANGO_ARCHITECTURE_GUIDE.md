# Django Architecture Guide — AI-Powered Demand Forecasting Platform

A beginner-friendly guide explaining how this Django backend is structured, how its apps connect, and how requests flow through the entire system.

---

## 1. High-Level Concept: What is Django?

Django is a high-level Python web framework that follows the **MVT (Model-View-Template)** pattern. In this project, Django acts as a **headless REST API backend**:

```
[React 18 + Vite Frontend]
       ↕ (HTTP JSON requests via Axios + JWT)
[Django REST Framework Backend]
       ↕ (ORM Queries)
[SQLite / PostgreSQL Database]
       ↕ (Feature Extraction & Inference)
[Machine Learning Engine (HistGBDT / Neural Net)]
```

## 3. What Does Each File Type Do?

| File | Purpose | Example from this project |
| :--- | :--- | :--- |
| **`models.py`** | Defines database tables as Python classes | `Product`, `Forecast`, `SalesTransaction` |
| **`views.py`** | Handles incoming HTTP requests and returns JSON | `ForecastViewSet.list()`, `login_user()` |
| **`serializers.py`** | Converts Django DB models to JSON and validates inputs | `ForecastSerializer`, `ProductSerializer` |
| **`urls.py`** | Maps URL routes (e.g. `/api/forecasts/`) to views | `router.register('forecasts', ForecastViewSet)` |
| **`settings.py`** | Central configuration for database, JWT, CORS, apps | `INSTALLED_APPS`, `DATABASES`, `SIMPLE_JWT` |
| **`management/commands/`** | Custom terminal commands via `python manage.py <name>` | `populate_sample_data`, `train_models` |
| **`migrations/`** | Database schema version history | Automatically generated by `makemigrations` |

## 5. How URL Routing & Django REST Framework Work

In `backend/demand_forecast_core/urls.py`:

```python
from rest_framework.routers import DefaultRouter

router = DefaultRouter()
router.register(r'forecasts', ForecastViewSet, basename='forecast')
router.register(r'products', ProductViewSet, basename='product')
router.register(r'inventory', InventorySnapshotViewSet, basename='inventory')
```

The `DefaultRouter` automatically creates standard RESTful endpoints:

- `GET /api/forecasts/` — List all forecasts (with query filters like `?sku=BEV-001&location=1`)
- `GET /api/forecasts/{id}/` — Retrieve a single forecast record
- `POST /api/forecasts/` — Create a new forecast
- `GET /api/forecasts/summary/` — Custom aggregate summary (via `@action`)
- `POST /api/forecasting/model-runs/trigger_training/` — Trigger retrain tournament

## 6. Authentication & Security (JWT)

1. **User logs in:** `POST /api/auth/login/` with username & password.
2. **Django issues two tokens:**
   - **Access Token:** Short-lived (2 hours) attached to every subsequent request in the `Authorization: Bearer <token>` header.
   - **Refresh Token:** Long-lived (7 days) used to request a new access token when it expires (`POST /api/auth/refresh/`).
3. **Role-Based Access Control (RBAC):**
   - **Admin:** Full access, can trigger model retraining tournaments and edit master data.
   - **Planner:** View forecasts, create purchase orders, manage alerts.
   - **Viewer:** Read-only access to charts and dashboards.

## 7. Command Execution Sequence

To build and run the entire backend from a clean slate:

```bash
cd backend

# 1. Apply database schema migrations
python manage.py migrate

# 2. Seed 54,544 historical transactions, SKUs, and locations
python manage.py populate_sample_data

# 3. Train all 4 ML models and evaluate tournament on holdout data
python manage.py train_models --split-date 2026-07-01

# 4. Generate 14-day forward predictions with 90% confidence bands
python manage.py generate_forecasts --horizon 14

# 5. Start the development API server
python manage.py runserver
```

## 8. Where to Find Specific Logic

- **Need to add or edit SKUs/Products?** → `backend/forecasting/models.py` & `backend/ingestion/services.py`
- **Need to adjust the ML models or hyperparameters?** → `backend/forecasting/ml_engine/models.py`
- **Need to change the 18 feature calculations?** → `backend/analytics/models.py` & `backend/ingestion/services.py`
- **Need to edit API endpoints or permissions?** → `backend/forecasting/views.py` & `backend/demand_forecast_core/urls.py`
- **Need to customize JWT token lifetimes?** → `backend/demand_forecast_core/settings.py` (`SIMPLE_JWT` dictionary)
